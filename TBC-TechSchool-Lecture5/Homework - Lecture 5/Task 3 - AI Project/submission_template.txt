2. ჩააკოპირე ზუსტი Prompts (მოთხოვნები), რაც გაუგზავნე AI-ს:

პრომპტი 1 (HTML/დიზაინისთვის):
"შექმენი სუფთა და თანამედროვე ერთგვერდიანი ვებ-აპლიკაციის index.html ფაილი Tailwind CSS CDN-ის გამოყენებით. თემაა: „კოსმოსისა და მეცნიერების ფაქტების ბარათები“ (CosmoFacts). გვერდზე უნდა იყოს: სათაური კოსმოსურ სტილში, კატეგორიების ფილტრის ღილაკები (ყველა, კოსმოსი, ფიზიკა, ბუნება, ტექნოლოგია), მთავარი ბარათი ფაქტისთვის, ღილაკი 'ახალი ფაქტი', ღილაკი 'რჩეულებში შენახვა', ტოსტ-შეტყობინების ველი და ქვემოთ ცალკე სექცია შენახული ფაქტებისთვის წაშლის ღილაკებით. სტილი იყოს კოსმოსური Dark Mode (slate-950 ფონით, ინდიგო/იისფერი აქცენტებით). JavaScript კოდი ცალკე script.js ფაილში უნდა იყოს გამოტანილი."


პრომპტი 2 (JavaScript ლოგიკისთვის):
"ახლა დამიწერე ამ პროექტისთვის script.js ფაილი. კოდმა უნდა გააკეთოს შემდეგი:
1. fetch() და async/await-ით წამოიღოს მონაცემები საჯარო სამეცნიერო API-დან, ხოლო თუ ქსელი გაითიშება, ჰქონდეს საიმედო ქართულენოვანი სათადარიგო ბაზა (fallback array).
2. DOM მანიპულაციით (textContent, createElement, appendChild, innerHTML) განაახლოს ეკრანი და რჩეულების სია.
3. ჰქონდეს კატეგორიების მიხედვით ფილტრაცია და დუბლიკატი ფაქტების შენახვის პრევენცია.
4. ღილაკებზე იყოს addEventListener-ები (მათ შორის დინამიურად შექმნილ წაშლის ღილაკებზე).
5. ჰქონდეს try/catch/finally ბლოკი შეცდომების დასაჭერად და ღილაკის ლოადერის ანიმაცია.
დამიწერე კოდი დეტალური ქართული კომენტარებით."


პრომპტი 3 (კოდის ახსნისთვის - Code Explainer):
"მე ვარ დამწყები დეველოპერი და ახლა ვსწავლობ JavaScript-ს. გთხოვ, ამიხსნა ზემოთ დაწერილი script.js კოდი ადამიანურ ენაზე, მარტივი ანალოგიებით:
1. რას აკეთებს async და await? (ამიხსენი რესტორნის ან შეკვეთის მაგალითზე)
2. რატომ გვჭირდება response.json()?
3. როგორ მუშაობს createElement და appendChild?
ამიხსენი მოკლედ და გასაგებად."

3. რა აგიხსნა AI-მ "ადამიანურ ენაზე"? (ჩაწერე შენი სიტყვებით 2-3 წინადადება, თუ რა გაიგე ახალი JavaScript-ის მუშაობის შესახებ):

პასუხი:
AI-მ ამიხსნა, რომ `async/await` ჰგავს რესტორანში შეკვეთას: სანამ მზარეული კერძს ამზადებს (სერვერიდან მონაცემები მოდის), მთელი რესტორნის მუშაობა არ იყინება, არამედ მხოლოდ ჩვენი ფუნქცია ელოდება `await`-ით შედეგს. `response.json()` საჭიროა იმიტომ, რომ ინტერნეტით მოსული ნედლი ტექსტი გადაითარგმნოს JavaScript-ის ობიექტად, რათა მასში არსებულ ველებზე წვდომა ჩვეულებრივად შევძლოთ (მაგალითად, data.text). ხოლო `createElement` და `appendChild` მუშაობს ისე, როგორც Lego-ს კუბიკის ჯერ ცალკე აწყობა და შემდეგ მთავარ კედელზე მიმაგრება.

4. წააწყდი თუ არა რაიმე შეცდომას (Bug) და როგორ დაგეხმარა AI მის გამოსწორებაში?

პასუხი:
დიახ, თავდაპირველად რჩეულების სიიდან წაშლის ღილაკზე (✕) დაჭერისას ელემენტი არ იშლებოდა, რადგან დინამიურად შექმნილ ღილაკებს გვერდის ჩატვირთვისას querySelector ვერ ხედავდა. AI დამეხმარა და ამიხსნა, რომ `addEventListener` უნდა მიგვება პირდაპირ `createElement`-ით ბარათის შექმნის პროცესში, ხოლო მასივიდან ელემენტის ამოშლა უნდა მომხდარიყო `savedFacts = savedFacts.filter(fact => fact.id !== id)` მეთოდით და შემდეგ გამოგვეძახა `renderFavorites()`.
